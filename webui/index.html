首次使用指南

1让 OneBot 连接到本程序
打开你的 OneBot V11 客户端，在「网络配置」中新建一条「WebSocket 客户端」：
  1. 点击启用，名称随意填
  2. URL 填入下方地址
  3. 消息格式选择 Array
  4. Token 选填，如果填了则两边必须一致
加载中...
保存后在 OneBot 或本程序的日志中查看是否连接成功。
2开启群聊功能
进入你想使用的群聊，发送：
/开启固车拾取
也可以在左边「群组管理」里手动输入群号添加。
3试试看
在群里发一条 12345（纯5位数字），机器人会自动把群名改成「xxx 12345」的格式。搞定！
4进阶：调整设置
左边「配置编辑」页面可以调整：
  • 匹配模式：严格（只认纯5位数字）或宽松（数字后面有别的内容也行）
  • 车牌位置：前缀（数字放群名前面）或后缀（放后面）
  • 监听端口：改了端口要重启 OneBot 才能连上
  • 管理员：添加固车助手管理员后只有这些人能用指令
也可以在群里用 /固车模式 来切换模式。
5关闭功能
在群里发 /关闭固车拾取，或者去左边「群组管理」删除对应群号。
